
# Prolog Practical Assignment - TP4 Solutions

![Prolog](https://img.shields.io/badge/Prolog-Programming%20Logic-blue)

Complete solutions to the Practical Assignment IV from the Programming Languages Laboratory course, implementing 15 essential Prolog operations on lists.

## 📝 Description

This repository contains my implementations of 15 Prolog exercises focusing on list manipulation, as required by the TP4 assignment. Each solution is contained in its own `.pl` file following the exact naming convention specified in the assignment.

## 📋 Exercises Implemented

1. **List Length**: `nelementos.pl` - Count elements in a list
2. **Maximum Value**: `maior.pl` - Find the largest element
3. **Average Value**: `medio.pl` - Calculate the mean of integers
4. **Append Element**: `inserirfim.pl` - Insert at list end
5. **Last Element**: `ultimo.pl` - Get the final element
6. **Adjacent Check**: `adjacente.pl` - Verify element adjacency
7. **Range Generation**: `gerar.pl` - Create number sequences
8. **List Reversal**: `reverter.pl` - Reverse a list
9. **Element Increment**: `incrementar.pl` - Add 1 to each element
10. **List Flattening**: `linearizar.pl` - Concatenate nested lists
11. **Run-Length Encoding**: `compactar.pl` - Compress consecutive duplicates
12. **Element Removal**: `remover.pl` - Delete all occurrences
13. **Single Rotation**: `rotacionar.pl` - Rotate list by 1 position
14. **N-Rotations**: `rotacionarn.pl` - Rotate list by N positions
15. **List Sorting**: `ordenar.pl` - Sort integer lists

## ⚙️ Usage

1. Ensure you have SWI-Prolog installed
2. Clone this repository
3. Run any solution file with SWI-Prolog:
   ```sh
   swipl -s filename.pl

4. Test with the example queries provided in each file
```
